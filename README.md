### 🚀 Featured project

#### [AI Page Designer](https://github.com/tabriznia-dotcom/wp-fast-api-ai) · WordPress plugin

Turns a written brief into an accessible, responsive draft page for the **block editor**, **Elementor** or the **classic editor** — using the AI provider the site owner chooses.

- The AI never writes raw HTML: it fills a strictly validated **Page Schema**, which is sanitized, accessibility-checked and converted into native blocks
- Nine-step wizard with responsive preview · English & Persian · full RTL support
- Encrypted API keys, SSRF protection, rate limits, privacy exporter/eraser, no tracking
- PHPUnit, E2E and axe tests · GPL-2.0
